# 接触距离有限对照（可独立删除）

用途：固定数据与对象，比较0.7、0.8、0.9、1.0 nm；不以“差异最大”作为选值标准。

输入：正式第一步居中结果。边界按正式方法在本目录测量一次，四个距离共用同一套中心链和浓相链名单。只改变距离，序列排除≤2，伙伴阈值1、5、10。Rg不依赖接触距离，本轮不重复计算。

```bash
# 在项目根目录
python -u cutoff_comparison/run.py
# 单组
python -u cutoff_comparison/run.py --simulation A18_T260
```

参数在run.py。每帧只搜索一次最大距离内的候选珠对，按严格小于各阈值筛选；只统计接触量、序列参与概率、伙伴及分布，不跑四套完整网络。

输出：`output/0p7nm`、`0p8nm`、`0p9nm`、`1p0nm`下按模拟编号保存summary、帧均值、序列概率和伙伴分布；`output/upstream`记录边界与每帧链选择。均值帧等权，SD/SEM来自固定时间块，不是独立重复。

打开 `notebooks/01_compare_cutoffs.ipynb` 生成对照图及汇总CSV。`profile_diagnostics.csv`中参与概率≥0.95的位置比例是预先定义的饱和诊断，不是物理正确性的判据。
